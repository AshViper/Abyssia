# Abyssia Texture Studio

バニラ/Modのテクスチャをベースに、**複数レイヤー＋色を個別指定**でテクスチャを作る・直す・一括管理するツール。

    run.bat                      # GUI起動（初回は PySide6 を自動インストール）
    run.bat list / check / export --all / import NAME / render NAME --out x.png / hue NAME --hue 30

## 使い方
- 左: Mod内の全テクスチャ一覧（block/item）。検索・絞り込み・複数選択。●=未保存、「未反映」=PNGとスペックに差あり。
- 中央: プレビュー（グリッド / 3×3タイル / 背景 / 出力済みPNGとの比較）。鉛筆・消しゴム・スポイトで手描き。
- 右: レイヤー一覧（ドラッグで並べ替え、目のチェックで表示切替）と設定。レイヤー種類:
  画像(バニラ/Mod, 色相・彩度・明るさ / グラデーションマップ / ティント, 他テクスチャとの差分抽出), 塗り/グラデ,
  ノイズ, ひび/切れ目(透過で抜くことも可), 継ぎ目/レンガ, 点/鉱石の粒, 縁取り/ベベル, 手描き。
  各レイヤーに 合成モード（乗算・スクリーン・消去など）・不透明度・「下がある所だけ」。
- **Ctrl+S = 保存して反映**（specs/*.json 保存 + assets の PNG 書き出し）。未管理のPNGは初回保存でスペック化されます。
- **一括編集**: 複数選択 → 色相/彩度/明るさを一括変更、レイヤープリセットの一括追加/削除（プレビュー付き）。
- 未管理のテクスチャを開くと現PNGが「手描き」レイヤーとして取り込まれ、そのまま編集・一括色替えできます。

## 仕組み
- スペック(`specs/<kind>/<name>.json`)が原本、PNGは書き出し結果。シード付きなので再現可能。
- `forge_textures.run()` と `gen_deep_assets.py` の最後で `apply_all()` を呼ぶため、ジェネレータを再実行してもStudioのテクスチャが優先されます。
- ロック済み(`tools/texture_locks`)テクスチャを保存した場合はロックファイルも更新します。
- バニラ画像は Gradle の client jar から直接読みます（`ABYSSIA_MC_JAR` で変更可）。派生物になるため公開時は CREDITS を確認。

## Texture Forge（手続き生成）との統合
Forge の生成機能（AI連携を除く）は **「Forge生成」レイヤー** として使えます（`＋ 追加` → Forge生成 / Forgeプリセットから）。
- 全13カテゴリ・バリエーション・素材・スタイル・パレット/アクセント・ベース/サブ/ひび色・全スライダー・色数・内部レイヤーON/OFF・仕上げフィルタ。
- 参考テクスチャ（バニラ等）の統計参照、「参考を再着色」、出力を「発光部分のみ」にして `_glow` 用の画像も作れます。
- `バリエーション…` で12種のシードを見比べて選択。Forgeプリセットの適用・保存（texture_forge/presets）。
- 左下 `Forgeパック一括生成…` で Forge のパックプリセット（鉱石/地形/植物/噴出孔）から新規テクスチャをまとめて作成（既存名はスキップ、未保存で作られるので確認後「全て保存」）。
- 他のレイヤー（ひび・継ぎ目・手描き等）と重ねられ、一括の色替えにも対応します。
