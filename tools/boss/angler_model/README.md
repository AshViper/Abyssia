# アビスアングラー（abyss_angler）の GeckoLib モデル生成

大海蛇（`tools/boss/serpent_model`）と同じ「Python で GeckoLib モデルを生成する」流れで、
アンコウ型のボスの geo / animation / テクスチャ / 約束ファイルを丸ごと書き出す。
**出力は手で直さない**（ここを直して流し直す）。共通の道具（`../boss_kit.py` `../boss_views.py`
`../check_animations.py`）は変えずに使う。

## 流す順番

```bash
python tools/boss/angler_model/build.py              # 1. geo / animation / texture / contract.json
python tools/boss/check_animations.py abyss_angler   # 2. ボーン名・キーの逆順・尺超えが無いか
python tools/boss/angler_model/preview.py            # 3. 六面図を out/ へ（目で確かめる）
```

- 3 は一部だけも描ける: `preview.py whole`（全身）/ `head`（頭と肩の拡大）/ `open`（顎を 45 度開いた頭）/
  `tail`（尾）/ `bent`（S 字に曲げた全身と、関節 1 を約 21 度折った頭〜seg_05 の上・下・横）/
  `oblique`（全身を 35 度ヨー・20 度ピッチへ向けた斜めの図。まっすぐと、関節 1 を折ったもの）
- 曲げた図は Java の描画と同じ置き方（各 root Bone を関節の中点へ運び、局所 -Z を前の関節へ向ける）で作る。
  関節あたり最大約 21 度。継ぎ目に割れ目や殻の内側が見えないかはここで見る
- 戦闘側（攻撃起点・部位切り分け・hurt/death/spawn・噛みつきの大口）は今回の対象外

## 中身

| ファイル | 役割 |
| --- | --- |
| `build.py` | 骨格・外皮・アニメーション・約束ファイル。冒頭の寸法と表を変えれば形が変わる |
| `atlas.py` | 512x512 のテクスチャアトラス（皮膚と発光）。色は `tools/boss_textures.py` の angler() を引き継ぐ |
| `preview.py` | 実テクスチャを貼った六面図（`out/`） |
| `contract.json` | 描画の Java 側との約束（build.py が書く） |

書き出し先:

- `src/main/resources/assets/abyssia/geo/entity/abyss_angler.geo.json`
- `src/main/resources/assets/abyssia/animations/entity/abyss_angler.animation.json`
- `src/main/resources/assets/abyssia/textures/entity/boss/abyss_angler_geo.png` / `abyss_angler_geo_glow.png`
  （旧描画が使う `textures/entity/abyss_angler.png` は触らない）

## 寸法と MODEL_SCALE

**MODEL_SCALE = 3**（AbyssAngler.SIZE。描画は `withScale(SIZE)`）。geo の 1 単位はゲーム内で
3/16 = 0.1875 ブロック、テクスチャ 1 画素も 0.1875 ブロック。体の板が 90x40 単位、背びれの膜が高さ
140 単位ほどになるので、アトラスは 512 にした（256 では領域に収まらず引き伸ばされる）。

| 量 | 実寸（ブロック） | モデル（単位） | 出典 |
| --- | --- | --- | --- |
| 関節間隔＝体節の長さ | 15 | 80 | AbyssAngler（頭＋9 関節） |
| 頭の殻（鼻先〜後ろ端） | 関節 0 の 15 前（顎先は 21.8 前の受け口）〜関節 1（15 後ろ）、幅 54、高さ 37.8+35.6 | z -116〜80 | 深海アンコウ型の球の頭（2026-11-21 作り直し、同日に後ろ端を関節 1 へ） |
| 顎の蝶番 | 関節 0 の 12.5 後ろ、y -12.5 | (0, -66.67, 66.67) | 口の裂け目の奥（口縁は吻へ斜めに上る） |

## 骨の約束（Java の描画）

- `head` と `seg_01`〜`seg_09` は **root 直下**。静止姿勢は一直線で、関節 j は (0, 0, 80j)、体の芯は y=0。
- `head` の pivot は関節 0（原点）。鼻先は -Z。子: `jaw`（pivot は蝶番）→ `teeth_lower`・`lure_chin_1..3`、
  `teeth_upper`、`lure_stalk`（額の付け根）→ `lure_bulb`（柄の先）、`lure_nape_1/2`、`fin_l` / `fin_r`（胸びれ）
- `seg_k` は関節 k-1（前）〜k（後ろ）、pivot は中心 (0, 0, 80(k-0.5))。長さ方向は -Z が前
- **頭と seg_01 は同じ向き**（どちらも関節 1→0）に置かれるので常に一体。seg_01 は頭の殻の内側に丸ごと
  入るので箱を持たない（位置合わせだけの骨）。頭の殻は関節 1（z 80）で切り、seg_02 が同じ外形で続く
- **継ぎ目は球関節**: seg_k（k ≥ 2）の前端は関節 k-1 を中心とする球面（高さ y ごとに x² + d² ≤ x(y)²、
  断面の半幅の 0.45 倍だけ前へ）で前の殻の内側へ入り、関節 k-1 で前の殻と同じ外形（頭とは ×0.985）、
  関節 k で次の体節の球面と同じ外形になる。袖・稜は無い。曲げると外側は縁の下から球面が出て継ぎ目を埋め、
  内側は前の殻へ潜る（数 % はみ出す）。seg_08 / seg_09 は体の芯を持たず尾びれだけ
- 体節の子: `seg_05_fin` / `seg_06_fin`（背びれ）、`seg_05_anal` / `seg_06_anal`（臀びれ）、
  `seg_07_fin`〜`seg_09_fin`（丸い扇の尾びれ。seg_09 のものは最後の関節の後ろへ張り出す）、
  `fin_pelvic_l/r`（腹びれ、seg_03）、`lure_back_1/2`・`lure_belly_1..4`（体の提灯、seg_03 / seg_04）
- Java は毎フレーム root の Bone の位置と回転を上書きする。子は animation（idle）に任せる。
  GeckoLib の符号は contract.json の `geckolib_conventions`（大海蛇と同じ文）

## 形の持ち方

| 部位 | 作り方 |
| --- | --- |
| 頭骨 | 指数 2.35 の丸い箱形の断面を 16 枚の板で 9 区間（`ring_loft`）。後ろ端は関節 1 で、稜は置かない |
| 下顎 | 縁がいちばん広い半分の椀（10 枚 × 10 区間）。頭骨より 16% 狭く、閉じると縁が口縁の内側へ入る。先は吻より 1 前（受け口） |
| 口の中 | 口蓋と口の床の板（青紫の畝）、動かない喉の管、奥の闇。顎を開くと見える（`open`） |
| 牙 | 上は口縁と顎の壁のあいだから顎の外へ垂れ、下は顎の縁に立つ（閉じたとき頭骨を抜けない長さまで）。どれも 3 本の棒で細る針。吻の牙と顎先の牙（各 2 本）は長い |
| 眼 | 大きい眼（半径 3.8）と小さい眼 3 つを頭骨の面に沿って置く。大きい眼は骨の眼輪と眉の稜。体の眼 3 つ（seg_03） |
| 提灯 | AnglerMesh.LURES と同じ柄の曲線（付け根 + 長さ ×（向き t + 曲がり t²））を 6 本の棒で。珠は柄の最後の向きと真下のあいだへ垂れる涙形（主は 8 角 × 5 区間、ほかは 6 角 × 3 区間） |
| 体節 | 断面は芯からの角度ごとの半径（`body_polar`。頭の殻の外形 `head_polar` と指数 2.25 の超楕円を混ぜる）。seg_02 24 枚 × 4 区間〜seg_07 10 枚 × 3 区間（`SEG_RINGS`）。前端の 1 区間が球関節 |
| 鰭 | 背・臀・尾びれは厚み 0 の縦の膜を 10 単位（尾びれは 5）ずつ並べ、棘・鰭条を骨色の棒で。胸・腹びれは `Kit.fan` |

## テクスチャの約束

- 体の板は左右で u が鏡写しになる。横向きに意味のある絵は描かない
- 絵の上端は面に沿って上る向き。眼・牙・角・棘・柄・珠は領域まるごと貼る（`STRETCHED`）
- 鰭膜（FIN / MEMBRANE）は上端が外縁。破れは画素の深さで決め（外縁から 2〜11 画素、ときどき深い裂け目）、
  縦の膜は z から切り出す位置を決めて隣の板と絵を続ける（`build.film`）。旧テクスチャと同じ部分不透明（120〜235）
- 発光は `_glow.png`。光らない画素は (0,0,0,0)。光るのは提灯の珠・眼・下脇腹の発光器 2 列・頭と顎の発光点・口の中の裏地
- 生成は座標のハッシュだけで、何度流しても同じ PNG
