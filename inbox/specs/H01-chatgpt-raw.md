以下の方針なら、**「深海拠点を手軽に建設できるが、既存の建築要素を食い潰さない」**設計にできます。Claude がそのまま実装へ落とせる粒度にしています。

H01 深海拠点モジュール建設システム

tier: Deep Sea / Tier 2
files: ModItems / ModBlocks / 建設処理 / 建設プレビュー / レシピ / BlockEntity不要
goal: 水中に土台・部屋・廊下・出入口・ムーンプールを組み合わせた拠点を一括生成できる建設アイテムを追加する。

constraints

Minecraft Forge 1.20.1。

深海層 Y=-368..-64 を主対象とする。

水源中に設置することを基本とする。

生成した専用ブロックは破壊してもドロップしない。

建設失敗時は素材を消費しない。

既存の industrial_panel 等とは別の専用建材を使用。

内部空間は水を除去してairにする。

建設物同士を接続できる寸法規格に統一する。

設置方向はプレイヤーの水平向きを基準とする。

accept

5種類のモジュールを選択して水中に生成できる。

Shift + 右クリック でモードを切り替えられる。

右クリックで選択中モジュールを建設できる。

必要素材が不足している場合は建設されず、素材も消費されない。

建設範囲内に既存ブロックがある場合は原則建設しない。

建設後、居住空間に水が残らない。

ムーンプールだけは指定位置に水面を残せる。

建設ブロックを破壊してもアイテムをドロップしない。

設計意図

建設装置自体は中盤以降の設備とし、単なる木材・鉄だけでは作れないようにする。

一方、各モジュールの建設コストはインベントリから直接支払うため、プレイヤーは

「建設装置を持つ → 必要な鉱石・インゴットを持つ → 現地で拠点を組み立てる」

という運用になる。

モジュール接続規格

全モジュールは中心線を共通規格にする。

        [ムーンプール]
              │
[部屋] ─ [廊下] ─ [出入口]
              │
            [部屋]

この規格を採用することで、後から

大型研究室

原子炉室

格納庫

農業室

潜水艦ドック

発電室

などを追加しても、H01の接続規格をそのまま利用できる。

**実装上の最重要ポイントは「5種類を個別に作る」ことより、各モジュールの座標原点・接続口・回転規則を共通化すること。**これを先に固定しておくと、Abyssia の将来の基地拡張がかなり楽になります。
