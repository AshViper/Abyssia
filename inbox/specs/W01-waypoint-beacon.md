## 確定仕様

| 項目 | 仕様 |
|---|---|
| ID | `waypoint_beacon` / 迷子対策ビーコン / Waypoint Beacon |
| モデル | 作業灯と共通。ランプ部だけ設定色で光る (tint) |
| 光源 | 15 (作業灯と同じ) |
| レシピ | `I R I / G W G / I C I` (I 鉄インゴット, R レッドストーン, G ガラス, W 作業灯, C 銅インゴット) → 1 |
| 右クリック | 名前・色の設定画面 (176x166) |
| 名前 | EditBox、最大32文字、trim、空は不可、初期値「迷子対策ビーコン」 |
| 色 | 16色プリセット 8列x2行 (16-18px マス)、選択中は白枠、ホバーで色名ツールチップ、「現在の色: ○○」、[保存] [キャンセル] |
| マーカー | HUD 上のひし形 12px (暗色アウトライン + 設定色)。下に名前 (最大幅160px、超過は…) と距離 |
| 距離書式 | `182m` / 1000m以上 `1.24km` / 10000m以上 `10.0km` |
| 遠距離 | サイズは縮めない。最大表示距離 512 |
| 画面外 | 画面端から16pxに寄せて表示、方向を示す小さな矢印付き |
| 重なり | 近いスクリーン座標のマーカーは上下にずらす |
| 共有 | サーバー全員に共有 |
| ディメンション | 同じディメンションのビーコンだけ表示 |
| 破壊 | 即座にマーカー削除。ドロップは本体1個、名前・色は引き継がない |
| 光柱 | なし。ランプから設定色の微弱パーティクル (数秒に数個) |
| Tick | BlockEntity tick なし |

### Config `[waypoint_beacon]`

client: `max_display_distance=512 (64-4096)`, `hide_within_distance=64 (0-512, これ以内は非表示; 2026-10-02 ユーザー指示)`, `show_distance`, `show_name`, `show_offscreen_marker`, `marker_size=12 (8-32)`
server: `share_beacons=true`, `max_name_length=32`

## Claude 補足 (実装方針)

- 512ブロック先はクライアントにチャンクが無いので、BlockEntity を総当たりしない。サーバー側に `SavedData` (ディメンション毎のビーコン一覧) を置き、ログイン/ディメンション移動/変更時に一覧パケットを全員へ送る。クライアントはその一覧だけで HUD を描く。
- 設定画面はコンテナ不要なのでクライアント Screen を直接開き、保存は C2S パケット (サーバーで距離・権限チェック、名前長 trim/切り詰め)。
- `share_beacons=false` のときは設置者にだけ送る (設置者 UUID を保持)。
- deep_ocean は overworld に統合済みなので、深海層と地上は同じディメンション扱い。
