依頼文の現状・制約を基準に、入手経路を増やしつつ「海樹脂が常時余る」状態にならないよう、自然生成の拡張＋プランター対応を中心にまとめました。

# RS01 海樹脂入手経路拡張

## tier
中盤向け資源拡張

## files
- `plant_resin` 関連の植物生成設定
- `amber_fan`
- `resin_root`
- 水耕プランターの作物登録
- 必要に応じて関連レシピ設定

## goal
海樹脂 `plant_resin` の入手可能な場所・方法を増やし、特定のバイオームへ移動しないと不足する状態を緩和する。
ただし、既存の希少性を維持し、大量生産が容易になりすぎないようにする。

## constraints

### 1. アンバーファンの自然生成拡大

既存:
- `abyssal_forest`
- `deep_forest`
- `abyssal_ocean`
- `cave:forest`
- 深さ 500～5000
- `tries: 12`

追加:
- `deep_sea`
  - 深さ 1000～5000
  - `tries: 4`
- `abyssal_trench`
  - 深さ 1000～5000
  - `tries: 3`
- `deep_crystal_fields`
  - 深さ 1500～5000
  - `tries: 2`
- `cave:abyssal`
  - 全深度
  - `tries: 3`

追加先では既存のアンバーファンと同じ収穫仕様を使用する。
- 通常破壊: 素材のみ
- シルクタッチ/はさみ: 本体取得
- 熟成後の右クリック: `plant_resin` を 1～2 個取得して再生
- 追加生成によって既存バイオームの生成密度は変更しない。

### 2. 樹脂根の自然生成拡大

既存:
- `cave:abyssal`
- `cave:forest`
- `cave:cavern`
- 全深度
- `uncommon`
- 先端から `plant_resin` を 1～2 個

追加:
- `cave:mineral`
  - 全深度
  - `uncommon`
- `cave:thermal`
  - 深部のみ
  - `uncommon`
- `cave:luminous`
  - 全深度
  - `rare`

既存の樹脂根の収穫量・収穫方法は変更しない。

### 3. 水耕プランター

水耕プランターの栽培対象に `amber_fan` を追加する。

仕様:
- 4区画のうち1区画でアンバーファンを栽培可能
- 通常のアンバーファンと同じ成長段階・熟成判定を使用
- 熟成後の右クリックで `plant_resin` を 1 個取得
- 収穫後は再成長する
- 種・苗の追加アイテムは作らず、アンバーファン本体を栽培開始アイテムとして使用
- 1区画あたり同時に1株のみ
- 成長速度は既存の資源植物と同程度とし、特別な高速成長補正は付けない

### 4. その他の入手経路

今回は以下を追加しない。
- 他植物からの副産物
- 古代樹などの木材からの入手
- モンスター/敵からのドロップ
- チェスト・構造物からの大量入手

海樹脂は「海洋植物・樹脂植物から得る資源」という位置付けを維持する。

### 5. 入手量の上限・バランス

以下を上限の基準とする。

- 自然生成植物からの1回の収穫量: 1～2個
- プランターからの1回の収穫量: 1個
- 新規の直接ドロップ経路は追加しない
- 既存レシピの `plant_resin` 必要量は変更しない
- 1株から短時間に大量取得できる高速成長仕様は禁止
- 自然生成の追加は「入手場所を増やす」ことを目的とし、既存バイオームの密度を大幅に上げない

特にプランターは安定供給手段になるため、自然生成より取得効率を高くしない。

## accept

- `plant_resin` を既存の2経路以外からも安定して入手できる。
- `amber_fan` が `deep_sea` / `abyssal_trench` / `deep_crystal_fields` / `cave:abyssal` に指定深度・密度で自然生成される。
- `resin_root` が `cave:mineral` / `cave:thermal` / `cave:luminous` に指定条件で自然生成される。
- 自然生成植物の収穫量は従来どおり 1～2個。
- 水耕プランターでアンバーファンを栽培でき、熟成後の右クリックで `plant_resin` を1個取得できる。
- プランター収穫後に株が再成長する。
- 他植物・古代樹・モンスター・チェスト等への新規入手経路は追加されていない。
- 既存の5レシピおよび既存の海樹脂の用途は変更されていない。
- 新規追加によって短時間で大量の海樹脂を自動生産できる状態になっていない。
- Forge 1.20.1 と NeoForge 1.21.1 の両実装で同一仕様になる。
