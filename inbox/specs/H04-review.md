# H04-H06/I03 review (ChatGPT, 2026-10-02)

検査結果

合格

全体として、依頼・H04〜H06仕様・デザイン画に対して主要機能は一致しています。特にロッカーの2×2一体感、作業台のFE充電、電動ツールのFE専用化、建設装置の立体化は問題ありません。

差異・改善点

【低】H04 ロッカーの見た目

2×2の4分割テクスチャによる大型ロッカーとして成立。

ただしスクリーンショットでは中央の継ぎ目がやや強く見えるため、中央シールを1px程度に抑えるとデザイン画の「1枚の大型ロッカー」感がさらに強くなる。

【低】H05 壁掛け作業台

壁固定・3×3クラフト・充電スロット・FEゲージ・ケーブル接続まで実装されており仕様達成。

作業面がやや薄く見えるので、支持アームをもう少し視認できる形にすると「壁掛け設備」感が向上。

【低】I03 電動ツール

FEのみ・耐久なし、ドリル3×3、カッターの切断機能ともに仕様以上。

FE残量を耐久バーとして表示しているため、操作上も分かりやすい。

カッターの精密切断を通常モードへ統合した点も問題なし。

【中】H06 建設装置：一人称

現状でも立体モデルとして成立しているが、スクリーンショットでは本体がやや大きく、画面右下を占有しやすい。

推奨 firstperson_righthand:

scale: 0.60〜0.65

translation: [0.5, 1.5, 0〜1]

回転は現状を維持し、先端レンズが画面中央側を向くよう微調整。

「工具を持っている」より「大型装置を抱えている」印象を少し弱めるのが狙い。

【中】H06 建設装置：三人称

現状は大きな破綻なし。

推奨 thirdperson_righthand:

scale: 0.55〜0.60

translation: [0, 1〜2, 0]

プレイヤーの手元から少し前方に出る程度にすると、ドリル等の工具とのサイズ感が揃う。

【低】H06 建設装置：GUI

平面アイコンを使用する調整仕様なので、現状で正しい。

3Dモデルを無理にGUI表示する必要なし。

【中】H06 建設装置：地面

地面アイテムは立体形状が確認できる。

ただし現在は少し横倒し感が強いため、ground の rotation を調整してレンズ側が上向き気味になる配置を推奨。

推奨目安:

scale: 0.45〜0.50

translation Y: 1.5〜2.0

rotation: [0, 0, 15〜25] 程度から調整。

【低】H06 建設装置：額縁

レンズ・グリップ・本体形状が確認でき、額縁表示として成立。

ただし額縁ではレンズが側面から見えにくい角度があるため、前部ハウジングを1〜2px程度前方へ出すと識別性が上がる。

H06 パーツ寸法について

現状のパーツ構成、

本体 / 前部ハウジング / 発光レンズ / 上部パネル / 側面表示 / ティール帯 / グリップ

は仕様通りで問題ありません。

モデル自体を作り直す必要はなく、表示トランスフォームの微調整だけで十分です。

特に優先するなら、

一人称 scale 0.60〜0.65 → 三人称 0.55〜0.60 → 地面 0.45〜0.50

の順で調整すればよいです。

判定：合格。
