# 目的

W02「迷子対策ビーコン(W01)の表示距離の仕様変更」に対応し、ビーコンHUDマーカーを近距離では非表示、それ以上の距離では常時表示できるようにする。

# 仕様

- `hide_within_distance` の既定値を **16** に変更する。
  - プレイヤーからビーコンまで **16ブロック以下**：非表示。
  - **16ブロックより遠い**：表示対象。
- `max_display_distance` は **0 = 無制限** とする。
  - 既定値を **0** に変更。
  - `0` の場合、距離による上限を設けない。
  - `0` より大きい場合は従来どおり、その距離を超えたビーコンを非表示。
- 画面外のビーコンを画面端の矢印で示す既存挙動は維持する。
- サーバーから受信済みの同一ディメンション内ビーコン一覧を、距離上限によって削除・制限する仕様には変更しない。
- 既存ユーザーのClientConfigは**自動移行せず、注記のみ**とする。
  - 既存の `hide_within_distance=64` / `max_display_distance=512` は、そのユーザーの明示設定として維持する。
  - 新規生成・設定ファイル再生成時のみ新しい既定値 `16 / 0` が適用される。
  - これによりユーザー設定を勝手に上書きしない。

# Config

対象：クライアント設定 `[waypoint_beacon]`

- `hide_within_distance`
  - 既定値：`16`
  - 範囲：`0..512`
  - 指定距離以下を非表示。
- `max_display_distance`
  - 既定値：`0`
  - 範囲：`0..1000000`
  - `0`：無制限。
  - `1以上`：指定距離を超えたビーコンを非表示。
- Forge 1.20.1 / NeoForge 1.21.1 の両環境で同等仕様とする。

# 変更対象

- `ClientConfig` の `waypoint_beacon.hide_within_distance`
  - 既定値を `16` に変更。
- `ClientConfig` の `waypoint_beacon.max_display_distance`
  - 既定値を `0` に変更。
  - 範囲を `0..1000000` に変更。
- HUDビーコンマーカーの距離フィルタ処理
  - `max_display_distance == 0` の場合は遠距離による非表示判定を行わない。
- 既存の画面外マーカー矢印処理は変更しない。
- 既存ClientConfigの値は自動書き換えしない。

# エッジケース

- 距離が **16.0ブロック以下** → 非表示。
- 距離が **16.0ブロックより大きい** → 表示。
- `hide_within_distance=0` → 近距離による非表示なし。
- `max_display_distance=0` → 遠距離による非表示なし。
- `max_display_distance` を設定した場合、近距離判定と遠距離判定の両方を適用する。
- 同一距離境界で判定が不安定にならないよう、仕様上「以下」「より大きい」を明確に実装する。
- 画面外のビーコンは、表示対象である限り従来どおり画面端の矢印で表示する。

# テスト

- 新規ClientConfigで `hide_within_distance=16`、`max_display_distance=0` が生成される。
- ビーコン距離 `15` / `16` / `16超` で表示判定を確認する。
- `max_display_distance=0` で遠距離ビーコンが表示されることを確認する。
- `max_display_distance=512` 等で従来の上限動作が可能なことを確認する。
- 既存ClientConfigの `64 / 512` が自動的に `16 / 0` へ書き換えられないことを確認する。
- 画面外ビーコンの端矢印表示が従来どおり動作することを確認する。
- Forge 1.20.1 / NeoForge 1.21.1 の双方で同一挙動を確認する。
