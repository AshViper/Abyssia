# AB04 広間の照明設計（プラン: ChatGPT、2026-10-09。レビュー: Claude）

依頼: 広間（large/massive/mega）の横向き視点が真っ暗で、参照画像（明るく読める大空洞）に届かない。照明のプランは ChatGPT が作成（CLAUDE.md §6）。

## ChatGPT のプラン（要点、原文は ChatGPT 会話「照明設計プラン作成」）
1. 光の階層: 遠景ランドマーク（シーランタン15/フロッグライト15/結晶10-15、100x100 あたり 4-8 群）、中景の壁・柱（ランタン/発光植物/グローストーン、20-32 群）、近景の足元・段差（海のピクルス/発光苔/ランタン、24-40 群）。スケール別: Large ランドマーク 1-2・中景間隔 12-18・近景 8-12・上限 12/チャンク、Massive 2-4・18-28・10-16・8、Mega 4-8・24-36・12-20・6。
2. 環境色: 平原=青緑/シーランタン、発光=シアン緑/発光植物、森=緑/フロッグライト、結晶=青紫/結晶クラスタ、熱=橙赤/マグマブロック+フロッグライト、氷=淡青白/シーランタン+ランタン、毒=黄緑/発光植物+ピクルス、異常=紫/紫結晶+泣く黒曜石。（標準ブロック光は RGB を持たないので、色はブロックの色で出す。）
3. ランドマーク（Large/Massive/Mega）: 天井の発光結晶群 1/1-2/2-3、巨大な発光柱 0-1/1-2/2-4、遠壁の光る窓・アーチ 1/2-4/4-6、島上の灯台状構造 0-1/1/1-2。広間 ID + ランドマーク ID から決定的に配置、窓は輪郭と要所だけ光らせる。
4. クライアント: 広間内だけフォグ距離 x1.35（約194）、フォグ色を環境色へ 0.65 寄せる、近景の澄み 12 ブロック、中景の霞の開始 0.35、遠景 1.0、暗さの下限 0.08（描画補正のみ。ブロック光やスポーン判定は変えない）。広間判定は既存データ（毎フレーム SDF を計算しない）。Iris 互換: 既存のフォグフックを拡張し、シェーダー内部は触らない。
5. 負荷: 生成時に 1 回だけ置く、総数上限、決定論（seed + hallCell + landmarkId）、SDF 再利用。追加処理 P95 <= 5ms/チャンク。
6. 受け入れ: 横向きで Mega の反対側の壁の輪郭と 3 つ以上のランドマークが識別できる／見上げで天井・鍾乳石・柱上部が判別／12 ブロック以内の段差・島の縁・入口が識別／近景明瞭・中景霞・遠景輪郭／10 環境で色が区別／光源数が上限内／同一シードで座標一致／Forge と NeoForge で起動・描画／変更前後を同座標・同視点・同描画距離で撮影。
7. 順序: 1 つの Mega 広間で最小実験 → フォグ調整 → 生成上限と時間の計測 → 決定性 → 10 環境へ展開 → 互換性。

## Claude のレビュー（実装時に補正する点）
- 光は水中でも 1 ブロックごとに 1 下がる（最大 15 ブロック先まで）。光源は周囲約 15 ブロックしか照らさないので、「遠景ランドマークで遠壁を明るくする」ことはできない。遠景を読ませるのは (a) 発光ブロックそのものの輪郭（光源ブロックは遠くからでも見える）と (b) クライアントの広間内フォグ・暗さの下限。壁・柱の中景光は、壁の面積に対して約 25 ブロック間隔のグリッド状に置く（Mega の壁面 ≈ 3.5 万 m² → 数十〜100 群）。
- 「1 チャンクあたりの上限」は広間単位の予算（群数）に読み替える: 広間の総数 = 面積/高さ × 密度、チャンク別の上限は偏りを避けるための保険に使う。
- 既存の `HallLook.glow`（壁・天井に埋め込む発光ブロック）と `beacons`（crystal_kelp の光の柱）、`window`（遠壁の光る窓）を拡張する形にし、新システムを作らない。
- クライアントは `DeepOceanClientEffects`（広間判定は `CaveAmbience.cavernFactor()` が既にある）の既存の洞窟フォグ（cavern_fog 設定）を広間用に調整する。
