goal: 「選ぶ → ホログラムで確認・回転 → 置く → 約1秒で組み上がる」流れにする。H01 の5モジュール・寸法・コスト・3x3 接続規格・回収不可は変えない。
constraints:
- 原本: inbox/specs/H02-chatgpt-raw.md (ChatGPT)。下記は Claude の修正込み確定版
- 修正1 (サブノーティカ準拠): メニューは **右クリック** で開く (G キーでも開ける)。ChatGPT 案の「右クリック=プレビュー確定」は不要 (装置を持っている間は常にホログラム)
- 修正2 (回転): **マウスホイール** で 90° 回転 (サブノーティカ準拠)。R / Shift+R も可。ホイールは装置を持っていてメニューが閉じている時だけ奪い、**Shift+ホイール** は通常のホットバー切替のまま
- 修正3 (素材): 建設開始時にサーバーで消費して予約し、中断したら全額返す (完成時消費＋巻き戻しより安全)
- 解体は H02 ではやらない (ChatGPT 推奨どおり)
- 最終判定はすべてサーバー。クライアントは mode と rotation だけを送り、位置はサーバーがプレイヤーの視線から再計算する
- Minecraft 標準操作を奪うのは「装置を手に持っている間」の 左クリック (破壊→建設)・右クリック (使用→メニュー)・ホイール のみ
accept: compileJava 通過。右クリック/G でメニュー、項目クリックで選択 (所持/必要数、不足は赤)。持っている間ホログラム (半透明のブロック、可=シアン/接続スナップ=水色/不可=赤/素材不足=黄)。ホイール/R で回転、向きはプレイヤーと独立。ハッチ近くを狙うと自動スナップ。左クリックで約1秒の組み上げ演出の後に完成、途中キャンセル (離れる/持ち替え/ログアウト) で元の水に戻り素材返却。室内に水が残らない

## 操作 (装置を手に持っている間)
| 入力 | 動作 |
|---|---|
| 右クリック / G | 建設メニューを開く・閉じる |
| 左クリック | ホログラムの位置に建設開始 (メニュー非表示時) |
| ホイール / R | 時計回り 90° (ホイール逆方向 / Shift+R = 反時計回り) |
| Shift+ホイール | 通常のホットバー切替 |
| Esc | メニューを閉じる |
G / R は Controls から変えられるキーバインド (カテゴリ Abyssia)。

## 建設メニュー (Screen)
- 縦一覧: アイコン (HAB3) / 名前 / 寸法 / 必要素材を「所持 / 必要」で、不足は赤。選択中は ▶ とハイライト
- ホイール/↑↓ で移動、左クリック/Enter で選択して閉じる、G/Esc で閉じる。開閉と選択で UI_BUTTON_CLICK
- 選択は C2S パケットで stack NBT `Mode` に保存

## ホログラム
- 実際に置かれる殻ブロック (床/壁/天井/窓/照明/ハッチ/扉) を元テクスチャのまま半透明 (α 0.4 前後) で描き、状態色を重ねる: 可=シアン、ハッチにスナップ中=水色、不可(水でない/衝突/生き物)=赤、素材不足=黄
- 接続口 3x3 は水色の枠で強調。プランが変わった時だけメッシュを作り直す (毎フレーム 800 ブロックを積み直さない)
- F1 では表示しない

## 回転
- stack NBT `Rot` (0-3)。初期値 = プレイヤーの向きに最も近い 90° (Rot 未設定時)。以後プレイヤーの向きと独立。C2S パケットでサーバーへ
- ハッチにスナップしたときの向きはハッチが決める (回転は無視)

## スナップ
- 照準のレイ (到達 6) が当たったハッチ、またはレイ上の点から 2 ブロック以内にあるハッチパネルを候補にする。複数なら照準に最も近いもの
- 条件: 範囲が全部水・衝突なし (H01 と同じ判定)

## 組み上げ (サーバー)
- 左クリック → C2S RequestBuild(mode, rot) → サーバーが plan を再計算・判定・素材消費 → 20 tick かけて殻を下の段から順に置く (室内の水は最後の tick に一括で空気化、ムーンプールの水面はそのまま) → 完成時に接続処理
- 進行中は金属音 (IRON / METAL place、ピストン音を薄く) と白/シアンの粒子。完成で METAL place + 薄い BEACON_ACTIVATE
- キャンセル条件: 建設者が 16 ブロック以上離れる / 装置を持ち替える / ログアウト / 範囲に別ブロックが置かれた。キャンセル時は置いた殻を水に戻し、素材を返す (インベントリが一杯なら足元にドロップ)
- 同時に 1 人 1 件まで
