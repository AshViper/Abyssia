Abyssia (Minecraft Forge 1.20.1 深海Mod) の設計担当として、次の4件の仕様書をまとめて作ってください。実装は Claude。H01〜H03 (深海拠点モジュール建設装置) の続きです。

## 依頼 (ユーザー原文)
大きなロッカー / 壁につけれる作業台 / 電動ツール (= 電動ドリル・カッター) / 建設ツールの3Dモデル

## 既存の前提
- 拠点ブロック: habitat_* (ダークガンメタル、ティール帯、シアンの照明)。工業ブロック I01: Forge Energy (FE)、energy_device (蓄電池 1,000,000 FE、アイテム充電スロットなし)、ケーブル網、機械は立方体ブロック。形のあるブロックは parts 定義 (要素の from/to/faces を 0-16 座標で列挙、UV は位置から自動) から JSON モデルを生成している。
- 既存ツール: abyssal_drill (PickaxeItem, Tier 耐久2200 速度12) と abyssal_cutter (SwordItem, Tier 耐久1500) は普通の耐久消費ツールで「エネルギー使用は未実装 (phase2)」。素材 drill_head / tungsten_tip / conductive_component / thermal_component / machine_frame、合金インゴット各種あり。
- 建設装置 habitat_constructor は今は平面のアイテムアイコン (16x16)。手に持つと平らな板に見える。
- 拠点内は空気、水中ではないので普通の作業ができる。

## 出してほしいもの (Markdown、短く、Claude がそのまま実装できる粒度、4件それぞれ)
各件: `# <ID> <title>` / tier / goal / constraints / accept と以下。ID は H04 ロッカー, H05 壁掛け作業台, I03 電動ツール, H06 建設装置モデル。

H04 大きなロッカー: スロット数・サイズ (1x2 ブロック? 2x2?)、置き方 (向き、マルチブロックの扱い)、開閉アニメや音、ホッパー連携、壊したときの中身、レシピ、見た目 (パーツ構成)。
H05 壁掛け作業台: 機能 (バニラ作業台と同じ 3x3 クラフト? 追加機能があれば)、壁への設置ルール (付いている壁が壊れたら?)、厚み・寸法、見た目 (パーツ構成)、レシピ。
I03 電動ツール: 電動ドリル / 電動カッターを新規アイテムにするか既存2種を電動化するか、FE 容量、1回の消費量、FE 切れの挙動 (耐久との関係)、充電方法 (どのブロックで・どう充電するか。壁掛け作業台や energy_device に充電機能を付ける案も可)、特殊能力 (ドリル=3x3採掘など、カッター=?)、ツールチップ/耐久バーでの残量表示、レシピ。
H06 建設装置の3Dモデル: 手持ちアイテムの立体モデルの parts 定義 (from/to 0-16, 各面のテクスチャ名)、寸法、配色、一人称/三人称/GUI での表示 (display 設定の考え方)、必要なテクスチャ一覧。
