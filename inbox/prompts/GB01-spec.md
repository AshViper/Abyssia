## 既存の前提
- 外部の本Mod (Patchouli 等) は依存に無い。JEI は任意連携 (無くても動く)。追加の必須依存は避けたい。
- 独自 GUI の前例: AbstractContainerScreen 系 (プランター・ロッカー・作業台・工業機械)、素の Screen (拠点メニュー・ウェイポイント)。GUI 背景 PNG は tools/ の Python スクリプトで生成し textures/gui/ に置く。
- 言語: en_us / ja_jp。
- Mod の主な内容: 深海層 (Y -368..-64) とバイオーム群、深海の岩・鉱石・鉱物、資源植物 (栽培・再生)、深海の動物と食料、潜水装備 (呼吸時間: 無し2分/入門5分/深海8分)、海流、拠点建設装置 (ルーム・廊下・ムーンプール・スキャン室)、工業 (FE の発電・ケーブル・機械)、ウェイポイントビーコン、水耕プランター、料理。

## 決めてほしいこと (短く、Claude がそのまま実装できる粒度)
`# GB01 <title>` / tier / files / goal / constraints / accept と:
1. 本アイテム: ID・名前、入手方法 (初回ログイン時に配布? レシピ?)、見た目 (アイテムアイコンの方向性)
2. 本の画面: 独自デザインのレイアウト (見開き/1ページ、目次、章、前後ページ、戻る)、配色・装飾のテーマ、画面サイズ
3. 構成: 章立て (ゲームの流れ順)、各章の内容、アイテム詳細ページの作り方 (アイテムのアイコン+説明、ページから何を引くか: 手書き / lang の説明 / レシピ表示)
4. データ形式: 本文をコードに埋めずにデータ (JSON + lang) で持つ形式の提案 (章 / ページ / テキスト / アイテム参照 / 画像)
5. 本文: ja と en の全文は別の返信で出してもらうので、ここでは章とページの一覧だけ
6. 必要な画像 (GUI 背景・アイコンなど) の一覧 (後でテクスチャとして生成を依頼する)
