Abyssia (Minecraft Forge 1.20.1 / NeoForge 1.21.1 の深海Mod、深海層は Y -368..-64、海面〜-64 はバニラ海+Abyssia バイオーム) の設計担当として、5件の仕様書を作ってください。実装は Claude。各仕様書は「# <id> <title>」「tier: light|standard|heavy」「files」「goal」「constraints」「accept」の形式で、Claude がそのまま実装できる粒度で短く。5件は files をなるべく重ねないこと。生成物 (lang/model/recipe/loot JSON) は Python 生成ツール (tools/gen_deep_assets.py, gen_fauna.py, gen_worldgen.py, seabed_structures.py) が書くので手書きしない前提で。

## 依頼1 GL01 (ユーザー原文): 堆積物を製錬することでガラスに加工できるように
既存: 海底の堆積物系ブロック (砂/泥/シルト/軟泥のようなもの。正確な ID は Claude が調べる) は今は精錬できない。バニラのガラスは砂の精錬だけ。
出してほしいもの: 対象とする堆積物の基準 (どれをガラスにするか、色付きガラス/特殊ガラスにするものがあればその表)、レシピ (かまど/溶鉱炉、xp、時間、個数)、新ブロックが要るならその表と必要テクスチャ。

## 依頼2 ST01 (ユーザー原文): 構造物のついか — 追加内容: 朽ち木 / 倒木
既存: 海底構造物はデータ表 (tools/seabed_structures.py) からグリッド配置で描くペインタ方式。木は「ancient」セット (ancient_stem 原木/stripped、ancient_frond 葉、ancient_planks 等) があり、苗木 ancient_sapling を別件で実装中。
出してほしいもの: 朽ち木 (立ち枯れ) と倒木 (横倒しの幹) の形 (高さ/長さ/太さの範囲、枝・根・苔/菌類の付き方)、使うブロック (既存 ancient セット優先、朽ちた見た目の新ブロックが必要ならその表とテクスチャ)、出現バイオーム・深さ・密度、壊した時に得られる物 (木材入手の補助になるか)。

## 依頼3 FS01 (ユーザー原文): 食料になる魚類の追加 — 8種類ぐらいほしい
既存: 深海の魚/生物は約30種 (アンコウ、フクロウナギ、ラブカ、ブロブフィッシュ等。モデルは自前ジェネレーター)、そのうち一部が魚肉 (abyssal_fish_fillet 2/0.3→焼き 6/9.6 等6種) を落とす。新種は gen_fauna.py の表 1行 + モデル定義で追加する方式。
出してほしいもの: 新しい食用魚8種の表 (id / 日本語名 / 英語名 / 実在のモデル魚 / 体長(ブロック) / 体色・特徴 / 出現深さとバイオーム / 群れ数 / 行動(群泳・底生など) / ドロップ (専用の生肉と焼き肉の id・満腹度・隠し満腹度・効果))。浅め〜深めに分散させること。モデル設計の要点 (パーツ・比率)、必要テクスチャ (アイテム16x16: 生/焼き)。

## 依頼4 BS01 (ユーザー原文): バイオームが広すぎる問題 — 一つのバイオームが広すぎて移動が長い。一つのバイオームが半径64チャンク程度でいろんなところに行きやすく
既存: 深海層のマクロバイオームはノイズ/セル方式 (gen_worldgen.py で生成)。現在の1バイオームはそれより大きい。
出してほしいもの: 目標サイズ (半径64チャンク≒1024ブロック、直径の分布)、隣接の偏り (同じバイオームが連続しない工夫)、端の遷移幅、既存ワールドへの影響の扱い (新規ワールドのみで可)、確認方法 (/abyssia map コマンドで地図を見る等) と合格基準。

## 依頼5 VD01 (ユーザー原文): 周りが見えなさすぎる問題 — 見える範囲を9チャンク程度に広げたい。あと、一度行った道に振り向くとFPSが下がる
既存: 深海の水中フォグを Mod 側で描いている (シェーダー対応の ShaderFogPass あり、設定はクライアント config)。視界はかなり短い。マリンスノー/海流パーティクルあり。
出してほしいもの: 視界の目標 (フォグ終端 = 9チャンク≒144ブロック、深さによる変化を残すか、設定項目と既定値)、暗さの雰囲気を保つ工夫 (遠景は暗く色だけ残す等)、FPS低下の調査方針 (原因候補: 訪問済みチャンクのキャッシュ蓄積、パーティクル、描画距離増に伴う負荷) と合格基準 (振り向いてもFPSが大きく落ちない、具体的な測り方)。

各仕様書の最後に「質問」欄は不要。不明点は妥当な既定値で決めてください。
