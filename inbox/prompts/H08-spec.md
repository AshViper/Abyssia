Abyssia (Minecraft Forge 1.20.1 深海Mod) の設計担当として、H08 の仕様書を作ってください。実装は Claude。

## 依頼 (ユーザー原文)
拠点の中にケーブルをあまりつけたくないので、外部から電気を入れれるようにして、拠点の中にはそのまま工業製品や作業台、レーダーを置くだけで電力が通るようにしてほしい。

## 既存の前提
- 拠点モジュール (H01-H07): 建設装置で 土台 / 多目的ルーム 13x13x5 / 廊下 5x7x5 / 出入り口 5x5x5 / ムーンプール 13x13x5 / スキャン室 5x5x5 を生成。接続口 3x3 ハッチが向かい合うと自動開通、ルーム同士は壁全面が結合。殻ブロック habitat_* は壊しても回収不可。
- 電力 (I01): Forge Energy (FE)。発電機 (熱水発電機は海底の噴出孔の近く = 拠点の外)、蓄電池 energy_device (1,000,000 FE)、ケーブル (128 / 512 FE/t)。CableNetworkManager がケーブル網をキャッシュ。
- 電気を使うもの: 工業機械 (粉砕機・精錬炉・合金炉・高温炉・選択浸出分離機)、壁掛け作業台 (充電スロット)、スキャン台座 (レーダー、20,000 FE、1 回 5,000 FE)、蓄電池。

## Claude からの実装方針案 (これを前提に詳細を決めてほしい。変えるべき点があれば指摘)
- 建設装置が完成させたモジュールの範囲 (箱) をワールドの保存データに記録し、接続・結合したモジュール同士を 1 つの「拠点」としてまとめる (後から繋いでも合流)
- 拠点の外壁に付ける新ブロック「給電ポート」(作業台で作る、普通に回収可能) が外のケーブルから FE を受け、拠点の共有電力に入れる。ポートは複数可
- 拠点の共有電力は、拠点内 (どれかのモジュールの箱の中) に置かれた FE を受け取れるブロックへ毎 tick 配る。ケーブル不要
- 拠点内の発電機・蓄電池の扱いは要検討

## 出してほしいもの (Markdown、短く、Claude がそのまま実装できる粒度)
`# H08 <title>` / tier / goal / constraints / accept と:
1. 給電ポート: ID・名前、置き方 (外壁に貼る? 殻ブロックと置き換え?)、受電量の上限 (FE/t)、内部バッファ、見た目、レシピ
2. 拠点の共有電力: バッファ容量 (ポート数で増える?)、配電の順番・公平さ、1 機器あたりの上限、損失の有無
3. 拠点内に置いた 発電機・蓄電池 の扱い (発電機は拠点に供給? 蓄電池は共有バッファの拡張?)
4. 拠点の判定: どこまでが「拠点内」か、モジュールが繋がっていないと別の拠点になること、既存の拠点 (記録前に作ったもの) の扱い
5. プレイヤーへの表示: 拠点の電力状態を見る方法 (ポートを右クリックで GUI / 表示?)、電力不足時の表示
6. サーバー負荷の注意
7. 必要なテクスチャ一覧
