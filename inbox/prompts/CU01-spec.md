水流をこういう感じで生成してほしい。
バイオームは関係なく生成してほしい。
これに入ると早めの勢いでながされるように
(参考画像: Subnautica の海中。白く半透明の細い筋が数十本束になって帯状に流れ、奥へ向かって広がる。筋は流れ方向に伸び、流れて動く。帯の外は普通の海。帯の幅は小型潜水艇より広い)

## 既存の前提
- 天然の海流 (NaturalCurrents): 世界の種から 192 ブロックのセルごとに確率 0.4 で 1 本。カプセル形 (A→B の線分 + 半径) または球の渦。深さ帯: 上層 Y 4..52、深海層 -330..-110。強さ WEAK 0.2-0.35 / NORMAL 0.4-0.7 / STRONG 0.7-1.0。地形は無視 (岩の中の部分は何も運ばない)。バイオームとは無関係だが数が少なく見つけにくい。
- 押し流し: 流れ方向の速度は 強さ x 減衰 x 0.16 ブロック/tick が上限 (ダッシュ泳ぎの方が速い)。プレイヤー/Mob/アイテム/ボートが流される。一部の生き物は抵抗、タグで無効。
- 見た目: 流れ方向に伸びた筋の粒子 (current_mote) をカメラ近くでまばらに出す (予算 600)。シェーダー (Iris/Oculus) でも見える必要あり (Mod 独自の ParticleRenderType はシェーダーで消える既知の問題)。
- 海流発電機が getCurrentAt の強さを使う (120 x 強さ FE/t)。
- 推進スクリュー (約 0.24 ブロック/tick)。

## 決めてほしいこと
1. 見た目: 参考画像のような「白い筋の束」を Minecraft でどう出すか (粒子の密度・大きさ・長さ・透明度・色、帯の外周の柔らかさ、遠くから帯として見える方法 — 粒子だけか、半透明のリボン/ボリュームを描くか)、描画距離と性能予算
2. 形と生成: 長さ・幅・曲がり (曲線にするか)、密度 (どれくらいの頻度で見つかるか)、深さ帯、バイオーム無関係の保証、地形との関係 (岩を突き抜ける/避ける)
3. 押し流し: 「早めの勢い」の数値 (中心の流速、縁への減衰、泳ぎや推進スクリューで逆らえるか)、入ったとき/出たときの加減速、対象
4. 既存の天然の海流を置き換えるか、別種として追加するか (発電機 API との関係)、コンフィグ
5. 必要なテクスチャ (粒子など) の一覧
