## 既存の前提 (現在の実装)
- 建設装置 habitat_constructor (サブノーティカの Habitat Builder 風): 持って右クリック/G = 建設メニュー、左クリック = 建設、ホイール/R = 90°回転。半透明ホログラム (シアン=OK/赤=不可/黄=素材不足)。建設は 20 tick かけて組み上がり、素材は開始時に消費・中断で返却。
- 現在のメニュー: 土台 13x13x1、ルーム 13x13x5、廊下 5x7x5 (内部 3x3)、出入り口 5x5x5 (外扉 1 枚の前室)、ムーンプール 13x13x5、スキャン室 5x5x5。接続は面中央の 3x3 ハッチで自動。13 幅同士は壁全面で結合し 1 空間。支柱は自動。殻ブロックは連結テクスチャ。
- 殻ブロック habitat_* は「壊しても何も落ちない」(ユーザー要件)。現在は解体機能なし。
- 拠点は 1 拠点ごとに共有 1,000,000 FE (無線給電)。外壁にケーブルを当てると受電、拠点内の FE 機器へケーブル無しで配電。
- ホログラムの位置: 照準先のブロック / 何も狙わないとき足元。ハッチ 2 ブロック以内に吸着。→ ユーザーは「もっと離れた位置、視点の先」に置きたい。
- 既存の設備 (今は普通のクラフトで作り手で置く): 大型ロッカー (2x1x2 マルチブロック、81 スロット)、壁掛け作業台 (3x3 クラフト + FE 充電スロット + 20,000 FE バッファ)。
- 既存の発電: 熱水発電機 (噴出孔の上、80 FE/t 基準 x 活動度 0-2)、工業ブロック (FE、ケーブル、機械は普通の立方体ブロック = ユーザー指定)。海流: 天然の海流ストリームがあり `getCurrentAt(pos)` で強さを取れる (タービン用 API)。生体油昆布 (バイオ燃料の素材候補)。
- スキャン室: 中央のスキャンコンソールが半径 32 / 高さ ±24 で鉱石をスキャン。
- 窓: habitat_window (連結ガラス) が殻ブロックとしてある。
- 梯子はまだ無い (室内の上下移動手段が無い)。
- 生き物: 深海の魚・ウナギ・サメ・クラゲ。捕獲アイテムはまだ無い。
- バニラの扉は開いていても水を通さない。

## 決めてほしいこと (短く、Claude がそのまま実装できる粒度)
共通: `# BT01x <title>` / tier / files / goal / constraints / accept を子仕様ごとに。
1. 建設メニューの構成 (カテゴリ: モジュール / 設備 / 発電 / カスタマイズ / 強化 など)、各項目のコスト素材 (既存素材で)、設置ルール (拠点の中だけ / 外壁 / 海底)
2. 解体: 対象 (モジュール単位? 設備単位?)、素材の返却率、拠点が分断されるときの扱い、浸水の扱い
3. 梯子: 見た目・寸法 (ルーム内で床〜天井、モジュールの上下接続も?)、上下に積んだモジュールの接続 (天井/床ハッチ) をやるか
4. マルチブロック発電機 3 種 (海流・地熱・バイオ燃料): 寸法、形状 (立体モデルか立方体か)、発電量、条件 (海流の強さ / 噴出孔 / 燃料と消費量)、拠点電力への接続方法
5. カスタマイズ: 壁→ガラス張り (どの範囲を一度に? 戻せるか)、扉のない出入口 (空気の膜 = 水が入らない開口、見た目)、充電ステーション (何を充電、速度、置き場所)
6. 強化: レーダー (スキャン室) 範囲アップグレードの段階・数値・コスト
7. 配置ガイド: 「視点の先」に置く距離 (例: 照準の先 N ブロック、ホイール/キーで距離調整など)
8. 水槽: 寸法、捕獲アイテム (仕様、対象の生き物)、育成・養殖のルール (増える条件・速度・上限・出力)、拠点内設置
9. 既存レシピの削除リスト (ロッカー・作業台など、建設装置で作るようになるもの)
10. 見た目の要るもの (発電機・水槽・充電ステーション・梯子・捕獲アイテム) の一覧。デザイン画は後で別に依頼する
11. 子仕様の分割と実装順 (依存関係)
