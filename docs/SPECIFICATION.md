# Abyssia 仕様書

> 作成日: 2026-10-04 / 対象: `main` (Forge 1.20.1) と `NeoForge1.21.1` ブランチ
> 元資料: Obsidian Vault `project/` のノート、`inbox/specs/*.md`、現行ソース

## 1. 概要

| 項目 | 内容 |
|---|---|
| MOD 名 / mod_id | Abyssia / `abyssia` |
| バージョン | 1.0.0 |
| 対応環境 | Minecraft 1.20.1 + Forge 47.4.10 (`main`) / Minecraft 1.21.1 + NeoForge 21.1.252 (`NeoForge1.21.1`、Java 21) |
| パッケージ | `com.abyssia` |
| ライセンス | All Rights Reserved |
| 任意連携 | JEI (なくても動く)、Iris / Oculus シェーダー (霧を独自に描き直す)、他 MOD の海洋生物 (自動検出してスポーン) |

**テーマ:** 実在の深海を Minecraft で探検する。実在種をもとにした深海生物、ひとつの深層岩の系譜でそろえた岩・鉱石・建材、
潜水装備、海底拠点、深海の資源だけで回る工業・食料の自給を備える。

**ゲームの流れ:**
海の割れ目から潜る → 深海層 (Y -368〜-64) を探検 → 植物・鉱物・生物の素材を集める → 潜水装備で長く潜る →
海底拠点を建てる → 発電と機械で素材を加工 → さらに深い海溝・熱水域へ。

## 2. ワールド生成

### 2.1 ワールドの層構造

旧 `abyssia:deep_ocean` ディメンションは廃止し、オーバーワールドの下に**深海層**として統合した (テレポートなし、新規ワールドのみ)。

```
Y  320 ┐
       │  上層 (バニラ地形 or Abyssia Ocean)
Y  -59 ┤  岩盤帯 (-64..-59)
Y  -64 ┤  深海層の天井 (下面は凹凸、-88..-72)
       │  深海層 (水で満たされた海、海底の大半は Y -100 以下)
Y -368 ┘  岩盤
```

- 深海層の判定は必ず `DeepLayer.isDeep(level, y)` で行う (ディメンション判定は使わない)。旧深海 Y = 新 Y + 240 (`DeepLayer.toDeepY`)。
- 生物は NBT `HomeDeep` で自分の層を覚える。

### 2.2 ワールドタイプ

| タイプ | 内容 |
|---|---|
| 既定 (normal を上書き) | バニラ地形 + 海の中に**深海の割れ目** + 岩盤の下に深海層。バニラの locate 結果は変わらない |
| Abyssia Ocean (`abyssia:ocean_world`) | 全面が海の大陸規模の海洋世界 (大陸棚 → 海岸 → 外洋 → 海溝)。深い裂け目 (rift) あり |
| Large Biomes / Amplified など | バニラのまま |

深海層への入口: 深海の割れ目 (`deep_fissure`)、海溝・海盆、深淵の裂け目 (`abyssal_rift`、Ocean のみ)。割れ目の中央は Y 62 から深海の海底まで水で通じている。

**設計ルール**
- バイオームは幅数百〜数千ブロックの連続した地域 (目標 直径 1500〜3000 ブロック。`BIOME_REGION_SCALE` 10.5)。モザイク状にしない。
- バイオームは大域ノイズ (macro / region_temperature / region_erosion など) だけで決め、局所の地形でバイオームを切り替えない。
- 深海層の 14 バイオームはタグ `#abyssia:deep_layer`。
- 生成は `tools/gen_worldgen.py` が JSON を出力する (**手で書き換えない**)。

### 2.4 地形・洞窟・海底構造物

- **洞窟網** (`worldgen/cave`): 大空洞、ガスだまり、空洞のランドマーク (例: 古代植物の空洞)。洞窟ごとの環境 (`CAVE_ENVIRONMENTS`) が植生と鉱物を決める。
- **海底構造物** (`worldgen/structure`): 汎用テンプレート 10 種 (火山、チムニー群、泥丘、ポックマーク、朽ち木・倒木など)。
  グリッドセル単位で配置を決め、チャンクごとに自分の列だけ塗る方式。データは `tools/seabed_structures.py`。
  高さは原則 Y 上限 (`max_top_y`) で打ち切り、開けた海を残す。
- **熱水噴出孔** (`thermal`): 噴出孔フィールド。活動度 (休止 / 弱 / 中 / 強 / 最大) を持ち、熱水発電機・高温炉が参照する。密度は 4 チャンクに 1〜2 個。

### 2.5 鉱物

岩は「一つの深層岩の系譜から分かれた別々の岩」に見えるようにそろえる。主要 7 岩には丸石 (`cobbled_<rock>`) があり、シルクタッチなしで掘ると丸石が出る (石の道具・かまどに使える)。

| 種類 | 例 |
|---|---|
| 独自鉱石 | コバルト、マンガン、ニッケル、モリブデン、タングステン、白金、バナジウム、テルル、イットリウム、硫黄、深海銅、深淵結晶、熱結晶 |
| バニラ鉱物の深海鉱脈 | 深淵の 鉄 / 金 / ダイヤモンド / エメラルド / ラピスラズリ / レッドストーン / クォーツ 鉱石。バニラのアイテムと経験値を落とす |
| クラスト | 鉱脈を囲む外殻 (`<鉱物>_crust`)。精錬可。ダイヤ・エメラルドのクラストは確率で宝石を落とす |
| 結晶塊 | アメジストの塊と同様の S/M/L 成長 |
| 建材 | クラストレンガ、磨かれたクラスト (階段・ハーフ・塀) |

鉱物アイテムの見た目の分類: 原石・インゴット・クラスト = バニラの原石/インゴット/原石ブロックの再着色、欠片 = クォーツ風、結晶塊 = アメジストの塊風、粉 = 染料風。

## 3. 深海生物 (59 種)

### 3.1 方針

- **実在種**をもとに、形態・深度・生息地・食性・動き方・生物発光を調べてから作る。確かでない点は「ゲーム上の簡略化」と明記する。
- スポーンは実際の深度と生息地で決める。大半は敵対しない (passive / neutral / predator / environmental)。
- **光るのは実際に発光器官がある部位だけ**。体色は彩度を抑えた暗い青灰〜シアン。
- 大きさの順 (ダイオウグソクムシ < チョウチンアンコウ < ダイオウイカ) は保つ。ゲーム内の長さ ≈ max(0.55, 1.4 × 実寸m^0.58) ブロック。
- 単独・群れ・群体を種ごとに決める。深海層にドラウンドは出さない。
- 分類上クラゲでない生物 (クダクラゲ、サルパ、クシクラゲ) をクラゲとして扱わない。和名は JAMSTEC BISMaL で確認する。

### 3.2 種一覧

|---|---|
| 魚類 (中深層〜超深海) | ハダカイワシ、トガリムネエソ、デメニギス、ホウライエソ、ミツマタヤリウオ、オオクチホシエソ、オニキンメ、オニボウズギス、チョウチンアンコウ、ヨロイダラ、オオイトヒキイワシ、ニュウドウカジカ、マリアナスネイルフィッシュ、ギンザメ、リュウグウノツカイ、ゲンゲ |

### 3.3 行動

| クラス | 対象 | 振る舞い |
|---|---|---|
| DeepSeaSwimmer / GenericSwimmer | 魚・頭足類 | 遊泳層 (外洋 / 海底近く / 海底)、日周鉛直移動、群れ、狩り、静止、逃避 |
| DeepSeaShark / GenericShark | サメ | 捕食者 |
| BenthicWalker / GenericWalker | 甲殻類・ナマコなど | 海底を歩く |
| DriftingMedusa / GenericMedusa | クラゲ | AI なし。ゆっくり沈み、傘の拍動で元の深さに戻り、地域の海流で群れごと流される。一部の種は刺す (ムラサキカムリクラゲの警報は大型捕食者を光へ呼ぶ) |
| Tubeworm | 固着生物 | 動かない。自然湧きは遠くで消え、スポーンエッグ等で置いたものは永続 |

### 3.4 スポーン

- `FaunaSpawner` + `data/abyssia/fauna_spawns/*.json` (深度 m、配置、生息地、底質、空間、上限)。
- 熱水域の種は噴出孔の周りにだけ湧く。
- 個体数上限はプレイヤー半径 128 ブロックで数える (総数上限 = max_per_player × 1.5)。
- **他 MOD の海洋生物**も自動判定して深海層に湧かせる (空気呼吸の生物は除外、他 MOD の比率は最大 35%)。設定 `abyssia-external-fauna.toml`、データ `data/<ns>/external_fauna/`。

### 3.5 ドロップ

| 対象 | ドロップ |
|---|---|
| 魚・ウナギ・サメ | 肉 (食料)。生→焼き (かまど 200 / 燻製器 100 / 焚き火 600 tick)。生の一部は確率で効果 |
| クラゲ 5 種 | 触手 (素材: 海洋接着剤、強化繊維、強化ケーブル、超深海殻板などのレシピ) |
| イカ・タコ・甲殻類・固着生物 | なし |

### 3.6 見た目

モデル・テクスチャ・アニメーションは `tools/bbmodel-generator` で生成し、`tools/gen_fauna.py` で Java とリソースへ同期する (手で作らない)。
歯・小さなヒレ・毛は厚みゼロの一枚板。発光は `FaunaGlowLayer` (光源ブロックは置かない)。

## 4. 植物・食料・栽培

### 4.1 資源植物

**すべての植物がクラフト素材を落とす** (観賞用だけの植物は追加しない)。定義表は `tools/plant_defs.py` の 1 か所。

- 基本素材 10: 深海繊維、植物樹脂、硬い茎、有機物、生体油、発光ゲル、深海顔料、耐熱繊維、結晶樹液、超深海の殻
- 加工素材 8: 繊維ロープ、海布、海洋接着剤、精製油、発光セル、耐熱フェルト、結晶レンズ、超深海殻板
- 採取: 実った植物 (`ripe`) を右クリックで素材を得て未熟に戻る。ランダムティックで再び実る。はさみなら +1。
- 設置した植物は未熟から始まる (無限増殖の防止)。柱状・ぶら下がり植物は先端だけが素材を落とす。
- 植物ブロック自体はシルクタッチ / はさみ (電動カッター含む) のときだけ落ちる。
- 生の海樹脂はハニカムと同様に銅を錆止めできる。
- 群落: 深淵の根のアーチ群落、深海の花群落、熱水チューブの森。

### 4.2 料理・食材

- 食材 3 (キノコの傘、ウリの果肉、海藻の葉) と料理 30 種。料理によっては効果 (バフ) が付く。
- 食用魚 8 種の生 / 焼き。深海サバイバル携行食 (生体油入り)。

### 4.3 自給

| 機能 | 内容 |
|---|---|
| 古代樹の苗 | 2 段階で育つ木。骨粉の成功率 45%。既存の ancient 木材セットを使う |
| 丸石 | 主要 7 岩の丸石で石の道具・かまど |
| 生体油昆布 | 最大 8 節、節ごとに実る油嚢。焼くと生体油 ×2。熟すと淡く光る (光レベル 4) |
| 水耕栽培プランター | 下付きハーフブロック、2×2 の 4 区画。食べられる植物なら何でも植えられ、3 分で育ち切る。収穫物はプレイヤーへ、苗は残って再成長。ホッパーで自動回収可。水も FE も不要 |

## 5. 潜水装備・道具

### 5.1 呼吸 (段階制)

段階 = max(頭, 胴) の装備。

| 段階 | 装備 | 水中で息が続く時間 |
|---|---|---|
| なし | — | 2 分 |
| 入門 | 簡易潜水ヘルム、簡易潜水タンク (バニラ素材) | 5 分 |
| 深海 | 深海潜水ヘルム、耐圧潜水ヘルム、潜水タンク | 8 分 |

- 息を延ばしている間だけ耐久が減る (入門 5 秒 / 深海 10 秒ごとに 1、胴を優先)。
- 水中呼吸・コンジット・呼吸エンチャントはバニラどおり重ねて効く。深海ヘルムは暗視付き。
- その他: 簡易潜水レギンス / フィン、潜水スーツのレギンス、深海フィン。設定 `[breathing]`。

### 5.2 道具

| 種類 | 内容 |
|---|---|
| 金属道具 | 深海合金 (剣・ツルハシ・斧・シャベル・クワ)、コバルト、マンガン、モリブデン、タングステン、結晶ツルハシ、深海ドリル / カッター |
| 電動アビサルドリル | 100,000 FE、1 ブロック 500 FE、スニークで 3×3 採掘。耐久なし (バー = FE) |
| 電動アビサルカッター | 75,000 FE、1 回 250 FE、はさみとして使える |
| 推進スクリュー | 水中で右クリック長押し、100 FE/tick、約 4.8 m/s。両手持ち |
| 迷子対策ビーコン | 名前と色 (16 色) を付けて置くと、全員の HUD にマーカーが出る (16 ブロック以内は隠す) |
| 深海ガイドブック | 初回ログインで 1 冊配布。章立てのチュートリアル (日本語 / 英語) |

### 5.3 エンチャント・効果

| 種類 | 名前 | 内容 |
|---|---|---|
| エンチャント | 深海遊泳 | 泳ぐ速さ +10%/Lv |
| エンチャント | 深海集中 | ヘルメット用。深海層にいる間、深海視界を得る |
| エンチャント | 熱処理 | 倒した魚の生肉を焼いた肉で落とす |
| 効果 | 深海潮流 | 泳ぐ速さ +15%/Lv |
| 効果 | 深海視界 | 深海の霧を遠ざけ、明るくする (I / II) |
| 効果 | 深海疲労 | 泳ぐ速さ -10%/Lv (サメ・ダイオウイカ・アンコウの攻撃で 5 秒) |
| 効果 | 冷却ショック | クロカムリクラゲの攻撃で 4 秒 |
| 効果 | 深海濁り | 霧が近く暗くなる (ムラサキカムリクラゲの攻撃で 6 秒) |

ポーションと料理バフで同じ効果を得られる。

## 6. 深海拠点 (Habitat)

### 6.1 建設装置

**深海拠点建設装置**を持っている間 (Subnautica 風の操作):

| 操作 | 動作 |
|---|---|
| 右クリック / G | 建設メニュー (カテゴリ: モジュール / 設備 / 発電 / カスタマイズ / 強化 / 飼育) |
| 左クリック | 建設 (20 tick かけて組み上がる) |
| R / Shift+R、ホイール | 回転、設置距離 (3〜12) |

- 半透明ホログラムで予告 (シアン = 配置可 / 水色 = ハッチに吸着 / 赤 = 不可 / 黄 = 素材不足)。
- 範囲がすべて水で、生き物がいない場所にだけ建つ。素材は開始時に消費し、中断なら全額返却。クリエイティブは無料。
- **解体**: 返却 80%。設備が残る部屋は解体できない。
- 拠点の殻ブロックは**壊しても回収できない** (ルートテーブルなし)。

### 6.2 モジュール

| モジュール | 寸法 |
|---|---|
| 土台 | 13×13×1 |
| ルーム | 13×13×5 |
| 廊下 | 5×7×5 (内部 3×3) |
| 出入り口 | 5×5×5 (外扉 1 枚の前室) |
| ムーンプール | 13×13×5 (中央 7×7 の水面) |
| スキャン室 | 5×5×5 |

- 接続口は面中央の 3×3 ハッチ。向かい合ったハッチは自動で開く。
- 13 幅のモジュール同士は壁を全面開放して一つの空間になる。2×2 結合で中央の柱も消え、ムーンプール同士はプールが一つにつながる。
- 屋根に吸着して上下に積める (縦ハッチ + はしご)。
- 支柱はグループの外角から海底まで自動で伸びる (最大 96)。
- 窓・壁・床・天井・照明は隣同士で連結テクスチャになる。

### 6.3 拠点の電力

- 完成したモジュールは一つの拠点として登録され、拠点ごとに 1,000,000 FE を共有する。
- 外壁に当てたケーブルで受電し、拠点内の FE 機器へケーブルなしで配電する。殻を素手スニーク右クリックで状態表示。
- **拠点発電機** (殻に接して設置、多ブロック立体):

| 発電機 | 出力 | 追加の建設コスト (共通: 機械枠 ×8) |
|---|---|---|
| 海流発電機 | 120 × 海流の強さ (上限 240 FE/t) | 導電部品 ×4 |
| 地熱発電機 | 噴出孔の熱に応じ 0/40/80/120/160 FE/t | 金インゴット ×8、熱部品 ×2 |
| バイオ燃料発電機 | 生体油 1 個 = 100,000 FE (100 FE/t) | 圧力バルブ ×2 |

### 6.4 設備・カスタマイズ

| 設備 | 内容 |
|---|---|
| 大型ロッカー | 2×2、81 スロット。ホッパー・配管対応 |
| 壁掛け作業台 | 3×3 クラフト + FE アイテムの充電スロット (20,000 FE) |
| スキャン室 | コンソールが鉱石・スキャン対象をホログラムで表示。1 回 5,000 FE。Lv1〜3 で半径 48 / 64 / 96 |

| 充電ステーション | 3 ブロック以内のプレイヤーに 200 FE/t |
| ガラス壁 / 空気膜 / 開放型出入口 | 空気膜は水を通さず、体は通れる |

## 7. 工業

### 7.1 エネルギー

- 単位は FE (Forge Energy / NeoForge の energy capability)。
- **ケーブル** (エネルギーケーブル / 強化エネルギーケーブル、流量 128 / 512 FE/t) はネットワーク単位で管理し、流量はネットワーク内で最も遅いケーブルの値。
- 分配順: 発電機 → 機械、発電機 → 蓄電池、蓄電池 → 機械。
- 蓄電: 深海エネルギーセル / 高度エネルギーセル。

### 7.2 機械

| 機械 | 処理 |
|---|---|
| 粉砕機 | 破砕ハンマーのレシピの出力 +1 |
| 精錬炉 | Abyssia の溶鉱炉レシピ |
| 合金炉 | 合金レシピの出力 ×1.5 |
| 高温炉 | 合金レシピの出力 ×1.5。半径 6 以内に休止していない噴出孔が必要 |
| 選択浸出分離機 | クラスト 1 (または精鉱 3) + 酸性浸出試薬 → 粉 ×3 + レア原石 8% (イットリウム 2%) |
| 熱水発電機 | 80 FE/t × 噴出孔の活動度 (0 / 0.5 / 1 / 1.5 / 2) |
| 補助発電機 | 燃料で 40 FE/t (石炭・木炭 80,000 FE、生体油 120,000、精製油 200,000) |

- 機械のレシピは JSON を持たず、既存のクラフト・精錬レシピから実行時に導出する (素材レシピを変えると機械も追従)。
- 機械・発電機・蓄電池は普通の立方体ブロック。立体モデルは配管・バルブ・ケーブル・照明だけ。
- 稼働中は動作音 (4 秒ループ 6 種) が鳴る。
- 熱水噴出孔ブロックは持ち運べない (ドロップなし)。

## 11. 開発・生成ツール

生成物は**手で書き換えず、生成元の表を直して再生成する**。

| ツール | 生成物 |
|---|---|
| `tools/gen_worldgen.py` | バイオーム・ノイズ・地物・海底構造物 JSON |
| `tools/gen_deep_assets.py` | ブロック・アイテムのモデル、レシピ、ルート、lang (各 `*_assets.py` を呼ぶ) |
| `tools/gen_fauna.py` | 生物の Java (Geometry / Animations / GeneratedFauna)、テクスチャ、音、スポーン、lang |
| `tools/plant_defs.py` / `plant_assets.py` | 資源植物 (`ModPlants.java` は生成物) |
| `tools/bbmodel-generator` | 生物モデル |
| `tools/forge_textures.py` / `texture_locks/` | 岩テクスチャ (ロック済みのものは再生成で消さない) |
| `tools/guide_text.py` | ガイドブックの本文 |
| `tools/machine_sounds.py` | 機械の動作音 |
| `tools/mc_format.py` | 1.20 → 1.21 のデータ形式変換 (NeoForge 用) |
| `tools/agentflow` | 依頼の管理 UI / CLI |

**実行順:** `gen_worldgen.py` → `gen_deep_assets.py` → `gen_fauna.py`

**テクスチャ:** 新しいブロック・アイテムのテクスチャは ChatGPT で作り、取り込んで `texture_locks` に固定する。

**2 ローダー運用:** 機能は Forge と NeoForge に同時に実装し、最後にパリティ監査を行う。データ形式の差は `mc_format.py` が吸収する。
